# PE Tracker · Russian PE / M&A Dashboard

Веб-приложение для анализа российского рынка Private Equity и M&A. Лента
новостей собирается **из реальных источников** (Telegram-канал `@dealsma` +
RSS деловых СМИ), мультипликаторы и структурированные карточки сделок —
справочные.

## Что умеет

- **Главный дашборд** — KPI рынка, график объёмов по секторам, карточки
  10 секторов, лента LIVE и последние сделки.
- **Страница сектора** (`/sector/[id]`) — описание сектора, KPI, таблица
  мультипликаторов (EV/EBITDA, EV/Sales, P/E, P/B), радар-чарт, сделки и
  отфильтрованная лента новостей сектора.
- **`/news`** — фильтры по сектору, важности и поиску; LIVE-лента с
  автообновлением каждые 6 секунд.
- **`/deals`** — структурированный реестр сделок с фильтрами.
- **Баннер источников** — на каждой странице сверху видно, реальные данные
  или фолбэк, сколько источников активно (X/Y) и когда был последний фетч.

## Источники данных (живые)

| Источник              | Что отдаёт                          | Тип фетча            |
| --------------------- | ----------------------------------- | -------------------- |
| `t.me/s/dealsma`      | Публичный preview Telegram-канала   | HTML + cheerio       |
| Коммерсантъ           | `kommersant.ru/RSS/news.xml`        | RSS                  |
| Ведомости             | `vedomosti.ru/rss/news`             | RSS                  |
| Интерфакс             | `interfax.ru/rss.asp`               | RSS                  |
| РБК                   | `rssexport.rbc.ru/.../full.rss`     | RSS                  |
| Forbes Россия         | `forbes.ru/newrss.xml`              | RSS                  |

Каждый пост проходит через классификатор:
- Раскидывается по 10 секторам по ключевым словам (`lib/sources/classify.ts`)
- Фильтруется по M&A / PE keywords (сделка, приобр, выкуп, IPO, fund, и т.д.)
- Помечается важностью (high / medium / low) по упоминанию сумм

Агрегатор кэширует результат **5 минут** (`CACHE_TTL_MS` в `lib/aggregator.ts`),
чтобы не дёргать источники на каждый запрос.

### Что НЕ парсится автоматически

- **Мультипликаторы по секторам** — закрытая аналитика брокеров (SberCIB,
  ВТБ Капитал, Альфа-Капитал и т.д.). Поправьте вручную в
  `lib/multipliers.ts`.
- **Структурированные карточки сделок** (`lib/deals.ts`) — извлечь
  «покупатель / продавец / сумма / доля» из произвольной прозы надёжно
  нельзя без LLM-пайплайна. Сейчас они тоже редактируются руками.
- Для реального потока сделок смотрите `/news` — там настоящий фид.

## Фолбэк

Если хотя бы один источник упал — он просто игнорируется. Если **все** упали
(нет сети, blocked outbound, rate-limit) — отдаётся демо-данные и баннер
честно говорит «Источники недоступны · показываются демо-данные».

Так, например, Claude Code online sandbox блокирует исходящий трафик — там
вы увидите жёлтый баннер. На локальной машине или Vercel — зелёный.

## Запуск

```bash
npm install
npm run dev       # http://localhost:3000
npm run build && npm start
```

## Архитектура

```
app/
  page.tsx                # главный дашборд (async)
  sector/[id]/page.tsx    # детали сектора (async)
  news/page.tsx           # лента (async)
  deals/page.tsx          # реестр сделок
  api/
    live/route.ts         # SSE-like polling: новые посты с момента since
    news/route.ts         # лента целиком или по сектору
    sector/[id]/route.ts  # снимок по сектору
    deals/route.ts        # реестр сделок
    multipliers/route.ts  # мультипликаторы
components/               # UI: Card, LiveFeed, Charts, Filters, DemoBanner
lib/
  types.ts                # доменные типы
  sectors.ts              # справочник 10 секторов
  multipliers.ts          # мультипликаторы (ручные)
  deals.ts                # структурированные сделки (ручные)
  news.ts                 # ДЕМО-фолбэк для ленты
  store.ts                # унификация: async getLatestNews и т.д.
  aggregator.ts           # главный агрегатор с кэшем + фолбэком
  sources/
    types.ts              # RawPost + fetchWithTimeout
    telegram.ts           # парс t.me/s/<handle>
    rss.ts                # парс RSS-лент (rss-parser)
    classify.ts           # сектор / deal-detection / importance / tags
  format.ts               # форматтеры (₽, %, дат)
```

## Стек

Next.js 14 (App Router) · TypeScript · Tailwind · Recharts · lucide-react ·
**rss-parser** · **cheerio**.
