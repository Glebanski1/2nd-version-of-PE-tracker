# PE Tracker · Russian PE / M&A Dashboard

Веб-приложение для анализа российского рынка Private Equity и M&A. Все материалы
разбиты по 10 секторам, по каждому — мультипликаторы, последние сделки и
новостная лента с обязательной ссылкой на первоисточник. Лента обновляется в
реальном времени.

## Что умеет

- **Главный дашборд** — KPI по рынку (объём, число сделок, YoY, топ-секторы),
  график распределения объёмов по секторам, карточки секторов, лента «LIVE»
  и последние сделки.
- **Страница сектора** (`/sector/[id]`) — паспорт сектора с описанием, KPI,
  таблицей мультипликаторов (EV/EBITDA, EV/Sales, P/E, P/B и др.), радар-чарт
  профиля мультипликаторов, лента сделок и новостей конкретно по сектору.
- **Все новости** (`/news`) — фильтры по сектору, важности и поиску; LIVE-лента
  с автообновлением каждые 6 секунд.
- **База сделок** (`/deals`) — фильтры по сектору, типу (M&A / PE / LBO /
  Buyout / Restructuring / IPO exit), статусу и поиску; счётчик объёма по
  выбранному срезу.
- **Real-time** — polling endpoint `/api/live` эмулирует поступление публикаций
  из Telegram-канала **@dealsma**, обновляя ленту без перезагрузки страницы.
- **Источники** — у каждой записи (сделка, новость, мультипликатор) указан
  издатель и кликабельная ссылка на оригинал.

## Секторы

IT и Технологии · Розничная торговля и FMCG · Финансовый сектор · Энергетика
и сырьё · Недвижимость и девелопмент · Промышленность · Фарма и
здравоохранение · Телеком и медиа · АПК и пищевая · Транспорт и логистика.

## Источники данных

- Telegram-канал **@dealsma** — оперативные публикации о сделках
- Деловые СМИ: Коммерсантъ, Ведомости, РБК, Forbes Россия, Интерфакс, ТАСС,
  CNews
- Аналитика: SberCIB Investment Research, ВТБ Капитал, Альфа-Капитал,
  Газпромбанк Инвестиции, БКС Мир Инвестиций, ИК Ренессанс Капитал
- Регуляторы и отраслевые институты: Банк России, Дом.РФ, DSM Group,
  RNC Pharma, ИКАР, INFOLine, TMT Consulting, JLL

> Подключение реальных RSS / Telegram Bot API делается на уровне `lib/store.ts`
> — данные хранятся в одном месте и могут быть заменены на live-источник без
> изменения UI.

## Стек

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** — кастомная палитра brand/ink, кастомные компоненты
- **Recharts** — bar chart по объёмам, radar chart по мультипликаторам
- **lucide-react** — иконки
- API-роуты `/api/live`, `/api/news`, `/api/deals`, `/api/multipliers`,
  `/api/sector/[id]`

## Запуск

```bash
npm install
npm run dev       # http://localhost:3000
npm run build && npm start
```

## Структура

```
app/
  layout.tsx             # глобальный layout с TopBar/Footer
  page.tsx               # главный дашборд
  sector/[id]/page.tsx   # детальная страница сектора
  news/page.tsx          # лента новостей + фильтры
  deals/page.tsx         # база сделок + фильтры
  api/                   # JSON API (live, news, deals, multipliers, sector)
components/              # UI-компоненты (Card, LiveFeed, Charts, Filters)
lib/
  types.ts               # доменные типы
  sectors.ts             # справочник секторов
  multipliers.ts         # мультипликаторы по секторам с источниками
  deals.ts               # сделки с источниками
  news.ts                # новости с источниками
  store.ts               # агрегация и эмулятор real-time
  format.ts              # форматтеры (₽, %, дат)
```

## Заметка

Данные носят демонстрационный характер и приведены в формате, готовом к
подмене на реальные потоки (Telegram Bot API для @dealsma, RSS деловых
изданий, API брокеров). Все ссылки на первоисточники — паттерны URL,
которые будут активны после подключения боевых интеграций.
